4. LGPL-2.1 — notices and §6 written offer
------------------------------------------

The LGPL-2.1+ libraries above are used as dynamically-linked libraries, and
proxy-libintl is statically linked into the (themselves LGPL) glib, json-glib and
spice-client-glib libraries. A distributed SpiceMac.app therefore carries,
under `Contents/Resources/Licenses/`, a copy of the LGPL-2.1 license text and this
notice (LGPL-2.1 §6 / §1).

Relinking with a modified library is supported and documented: SpiceMac is fully
open source (MIT). A recipient of a binary can rebuild it against their own
modified LGPL library — replace the relevant `.dylib` under
`Contents/Frameworks/`, or rebuild it from source and re-run
`scripts/build-app.sh`, then re-sign. The complete build recipe is in the repo
(deps/, scripts/build-deps.sh, Package.swift, scripts/build-app.sh). This provides
the §6(b) relink path.

date you received a given SpiceMac binary, the maintainer will provide, to any
third party, the complete corresponding machine-readable source code for the

charge no more than the cost of physically performing source distribution.
Request it by opening an issue at https://github.com/Ching367436/spice-mac (or
contacting the maintainer via GitHub). Upstream sources for these versions are
also publicly available at the URLs pinned in deps/sources.lock (GNOME,
